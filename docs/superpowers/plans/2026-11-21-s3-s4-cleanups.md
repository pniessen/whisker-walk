**Goal:** Split four jobs out of `src/world/builder.js` (S3) and replace the copied test canvas stubs and fake storages with shared helpers (S4), with nothing a child sees changing.

**Architecture:** S3 is a pure move done by a script (`move.mjs`) that takes named top-level declarations, with the comments above them, out of builder.js into a new file in their original order; builder.js re-exports every moved export and imports back what it still uses; core helpers the moved code needs get `export` in builder.js and are imported back from `./builder.js` (a cycle, safe because no moved file touches a builder.js binding while modules load, the same rule dressing.js already lives by). S4 adds `test/helpers/canvas.js` and `test/helpers/storage.js` and edits only each test file's setup header.

**Tech Stack:** Three.js, plain ES modules, Vite 8 (rolldown), Vitest 4.

## Review Focus

2. A comment left saying "above"/"below"/"in this file" about something now in another file: each S3 task fixes those comments, comment text only.

5. A place chunk growing because a moved module lands in it (or start-up growing): checked with `npm run build` after each S3 task.
