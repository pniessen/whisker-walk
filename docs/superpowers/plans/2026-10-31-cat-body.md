# Cat Body Reshape Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the "baguette with legs" cat body with the approved Version 2 shape, at no extra draw calls. Version 2 has a shorter body on longer legs, a shaped torso with painted coats, strong hind legs, a chest under the chin and a rooted, curling tail. The cute head, every coat, every pose and every accessory keep working.

**Architecture:**
- The torso becomes ONE vertex-coloured mesh, built by `torsoGeometry()` (the sketch's `catTorso()` deformation) in a new `src/cat/torso.js` and painted by `paintCoat()` in a new `src/cat/coat.js`.
- The extra shapes (chest, thighs, tail joints) are merged into meshes that already exist.
- The animator treats every cat as a long-legged cat measured against the old "reference rig", so the existing pose numbers keep working. It also takes ownership of the tail's curl in resting states.

**Tech Stack:** Three.js 0.185 (`three`, `three/examples/jsm/utils/BufferGeometryUtils.js`), Vitest 4, Vite 8. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-31-cat-body-design.md`, including the controller rulings R1–R5 in its §3. The visual target is the "Version 2" code in `cat-shapes.html` (session scratchpad, r128). Every number marked *(sketch)* is copied from it.

## Global Constraints

- Branch from `main` (4b09d01 or later). Three.js stays at 0.185. No new npm dependencies.
- **Mesh count per cat never goes up.** Final ceilings (full / simple):

  | Preset | Ceiling |
  |---|---|
  | tabby | 30/24 |
  | siamese | 30/24 |
  | persian | 30/24 |
  | black | 30/24 |
  | calico | 31/25 |
  | mainecoon | 30/24 |
  | zeetoo | 30/24 |
  | robbie | 31/25 |
  | d2 | 31/25 |
  | digit | 34/28 |
  | hagrid | 19/19 |

  No accessory adds more meshes than it did before the reshape.
- **Triangle caps:** a bare full cat has ≤ 8,000 triangles; a bare simple cat has ≤ 5,500.
- **Hagrid is byte-identical**, built and animated in every state, through every task. `buildChicken` is not touched. Each animator change is a no-op for a rig without `tailCurl`, `legLift` or `underside`, and writes `0`, never `-0`.
- **Determinism:** nothing in the model reads `Math.random`, `walkRng` or the clock.
- **The head is unchanged** except for `head.position = (0, 0.70, −0.40)` and `head.scale = 1.06` *(sketch)*. Whiskers are drawn exactly as today.
- **Nothing on the wire changes.** Profiles still carry `{ breed, accessories }`. `SAVE_VERSION` is untouched.
- **Ground rule (R2):** in every pose, bare and dressed, no point of a cat is more than 1 cm below y = 0.
- **Pose heights (R1):**
  - In the standing states `STANDING = ['follow','sniff','stretch','groom','pounce','scared','cross','land']`, the torso sits higher than the old rig by exactly the added leg lift, ± 2 cm.
  - In the crouch states `CROUCH = ['nap','stalk','perch','requestPet']`, the torso rests where it did, ± (1 cm sink, 2 cm hover), except where the old rest was under the ground (R2).
- Painted colours are built with `new THREE.Color(hex)` (linear working space), so a painted base matches today's `material.color` exactly. Painted meshes use `litMaterial(0xffffff, { vertexColors: true })`.
- The limb's bottom radius stays **0.058** (today), not the sketch's 0.056: the paw's width was tuned against 0.058 (model.js paw comment), and 2 mm is invisible at play distance.
- **Commits** use explicit `git add <paths>`, never `-am`. Every message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Goldens are regenerated deliberately**, with `UPDATE_GOLDEN=1 npx vitest run test/catgolden.test.js`. The diff must touch only the keys listed in the task's **Golden changes** line. `hagrid:*` keys are never rewritten (the writer skips them).

- Produces (in `test/helpers/catfingerprint.js`):

  - `fingerprintCat(cat) → { meshes, tris, box: number[6], lines: string[] }`:
    - one line per `isMesh || isLine` object, in `traverse` order;
    - format: `` `${depthPath}|${geometry.type}|v${count}|p${posHash}|c${colourKey}|t${+material.transparent}|vc${+!!material.vertexColors}|${pos}|${quat}|${scale}` ``;
    - `posHash` is the existing weighted sum over `r4` positions;
    - `colourKey` is the `color` attribute's weighted sum if one exists, else `material.color.getHexString()`;
    - `pos`, `quat` (`quaternion.toArray()`) and `scale` go through `r4`.
  - `buildFor(key: string) → THREE.Group`. Keys are `` `${breed}:full` ``, `` `${breed}:simple` `` (`{ simple: true }`), `` `${breed}:dressed` `` (`DRESSED`), and `` `hagrid:${state}` `` (bare Hagrid after `animateCat(cat, state, 1.3, 0, false)`), plus `hagrid:walk` (`animateCat(cat, 'follow', 2.7, 1.5, false)`), `hagrid:full` and `hagrid:dressed`.
  - `goldenKeys()` returns the 30 preset keys; `hagridKeys()` returns the 15 Hagrid keys (12 states, walk, full, dressed).
  - `poseMeasure(cat, state, t = 1.3) → { min, max, torsoMin, torsoMax }`:
    - runs `animateCat(cat, state, t, 0, false)`;
    - takes **precise** world `Box3` y-extents (`new THREE.Box3().setFromObject(obj, true)`, which boxes the vertices, not each mesh's tilted bounding box) divided by `cat.scale.x`;
    - the "torso" is `parts.body` (recursive) plus `cat.children[1]` when that is a `Mesh` (the separate belly, until Task 6).
  - `meshCount(obj)`, `triangles(obj)`.
  - `surfaceHit(objects, centre: Vector3, towards: Vector3) → Vector3 | null`. It casts from **outside**, from `centre + 3·dir` back along `−dir` (`dir` = the unit vector from `centre` to `towards`), and returns the first hit on `objects` (recursive). A ray cast from inside a closed mesh misses its front faces.

`deformTorso` is the sketch's loop body with its constants named:

```js
const front = Math.max(0, -z), back = Math.max(0, z);
const waist = Math.exp(-((z - S.waistZ) ** 2) / S.waistW);
let kx = 1 - S.waist * waist + S.hips * back * back;
let ky = 1 + S.chest * front - S.waistDrop * waist;
if (y < 0) ky *= 1 + S.chestLow * front - S.tuck * back * back;
const haunch = Math.exp(-((z - S.haunchZ) ** 2) / S.haunchZW) * Math.exp(-((y - S.haunchY) ** 2) / S.haunchYW);
kx *= 1 + S.haunch * haunch;
x *= kx; y *= ky;
if (y > 0) y += S.backRise * (z + 1) * 0.5 * (1 - x * x);
return [x, y, z];
```
